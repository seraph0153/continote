# 콘티노트

기준곡 하나로 시작하는 찬양 콘티 도구예요. 무료이고, 설치 없이 링크로 열어 쓰거나 홈 화면에 앱처럼 설치할 수 있어요.

## 할 수 있는 것

- **악보 불러오기**: 악보 그림 파일(폴더째 또는 사진)을 불러오면 파일 이름으로 곡 목록을 만들어요. `시선 D.png`, `은혜 Em(G).jpg`처럼 곡명 뒤에 키를 붙여 두면 키도 자동으로 들어가요. `(성탄)` `(부활)` 같은 괄호 표시는 절기로 읽어요.
- **기준곡과 같은 키 후보**: 기준곡을 고르면 같은 키 곡과 반음·온음 높은 곡(내려 부를 키로)을 모아 보여 줘요.
- **화음 듣기**: 키·장단조를 고르고 코드(3화음, 7화음, 자주 쓰는 코드)를 눌러 피아노 소리로 들어요. 건반을 눌러 한 음씩 들을 수도 있어요.
- **진행 듣기**: `1 5 6 4`, `2m7 57 1`처럼 번호로 코드 진행을 적어 들어요.
- **마디 진행**: 4/4·3/4·6/8·12/8 박자 칸에 코드를 끌어다 놓고 메트로놈에 맞춰 연주해요. 컴퓨터 숫자키 1~0으로 바로 치거나 녹음할 수 있어요.
- **콘티 파일**: A4 가로에 2곡씩 악보를 배치해 PDF나 이미지로 저장해요. 폰에서는 공유 창으로 카카오톡에 바로 보낼 수 있어요.
- **기록**: 저장한 콘티로 곡마다 마지막으로 부른 날·횟수, 많이 부른 곡, 오래 안 부른 곡을 보여 줘요.

## 개인정보와 저작권

- 악보·곡 목록·기록은 **쓰는 사람의 기기 안(브라우저 저장소)에만** 저장되고 서버로 보내지 않아요.
- 기기를 바꾸기 전에는 **설정 → 백업 파일 만들기**로 곡 목록·기록·설정을 옮기세요. 악보 그림은 새 기기에서 다시 불러와야 해요.
- 악보의 저작권은 각 저작권자에게 있어요. 이 앱에는 악보가 들어 있지 않고, 각자 가진 악보를 불러와 씁니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `docs/` | 공개용 웹앱(GitHub Pages에서 이 폴더를 그대로 배포) |
| `src/conti.src.html` | 앱 원본(claude.ai 개인판과 공개판이 함께 씀) |
| `tools/make_pwa.py` | 원본 → `docs/index.html` 공개판 만들기 |
| `tools/build_app.py`, `tools/build_songs.py` | claude.ai 개인판 만들기(개인 곡 목록은 `private/`, 저장소에 올리지 않음) |
| `tools/icon/` | 앱 아이콘 원본 |

## 공개판 다시 만들기

```bash
python3 tools/make_pwa.py
```

`docs/sw.js`의 `VERSION`을 올리면(예: `continote-v2`) 이미 설치한 사람들도 다음에 열 때 새 버전을 받아요.
